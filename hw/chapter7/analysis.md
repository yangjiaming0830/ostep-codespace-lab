# Chapter 7 CPU Scheduling Analysis

## Q1: FIFO、SJF 与 RR 对比（工作负载：100, 200, 300）

### 1. FIFO 结果
- 平均响应时间：133.33
- 平均周转时间：333.33

### 2. SJF 结果
- 平均响应时间：133.33
- 平均周转时间：333.33

**分析**：在本例中，SJF 和 FIFO 表现完全一致。原因在于作业长度刚好按 100、200、300 的顺序排列（从短到长），且假设同时到达。SJF 每次选择最短作业时，恰好与 FIFO 的执行顺序相同。

### 3. RR 结果（时间片 = 5）
- 平均响应时间：5.00
- 平均周转时间：461.67

**分析**：RR 算法的时间片设为 5，频繁发生上下文切换。
- **优势**：平均响应时间只有 5.00，远低于 FIFO/SJF 的 133.33。因为每个任务都能很快获得 CPU，用户体验更好。
- **劣势**：平均周转时间增加到了 461.67。因为任务被切得很碎，所有任务几乎要等到最后才能全部完成。

**结论**：RR 适合需要快速响应的分时系统，而 FIFO/SJF 适合追求整体完成时间的批处理系统。
